# NOVA Digital — International Launch Kit

This is a static website and prospecting starter kit designed for GitHub Pages.

## Included
- `index.html`, `styles.css`, `script.js`: responsive portfolio website
- `config.js`: contact email and future project links
- `prospecting/lead-tracker.csv`: starter lead tracker
- `prospecting/outreach-playbook.md`: agency and direct-client outreach process

## Before publishing
1. Open `config.js`.
2. Replace `YOUR_BUSINESS_EMAIL@example.com` with a real email address you control.
3. Confirm that the ARIYO domain is active before adding its URL.
4. Add Thelma's live URL after deployment.
5. Review all project descriptions and make sure each feature shown is accurate.
6. Add real screenshots when available. The current project visuals are CSS-built illustrative previews, not screenshots of the live sites.

## GitHub Pages deployment
1. Create a public GitHub repository named `nova-digital-portfolio`.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. In GitHub, open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and test the URL on mobile.

## Important trust and payment practices
- State clearly that NOVA is based in Nigeria and serves clients internationally.
- Use consistent, truthful identity, location, tax and payout information on platforms.
- Agree scope, milestones, timeline, revision limits and payment terms in writing.
- For direct projects, use a written agreement and an appropriate deposit/milestone structure.
- For marketplace projects, keep communication and payment within the platform's rules.
